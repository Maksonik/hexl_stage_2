# Учебная практика 14.09.2026

Все команды запускаются из директории
`Учебная практика 14.09.2026/`.

## Требования
- PostgreSQL 16+ (БД `practice_db` со схемой из практики 07.09.2026)
- Python 3.10+
- Пакеты: `psycopg2-binary`, `pytest`, `coverage`

```bash
pip3 install psycopg2-binary pytest coverage
```

## Полный цикл запуска

Все команды выполняются из директории `Учебная практика 14.09.2026/`.

```bash
# 1. Схема и данные из практики 07.09.2026 (уже готово в practice_db)

# 2. Дополнительные продажи (скидки 5/10/15% + партнёр без истории)
psql -d practice_db -f "Наполнение интерфейса, отладка и стресс-тестирование/seed_sales.sql"

# 3. Unit-тесты бизнес-логики + покрытие (discount.py = 100%)
python3 -m pytest "Разработка ядра бизнес-логики (Расчет скидки)/test_discount.py" -v

cd "Разработка ядра бизнес-логики (Расчет скидки)"
python3 -m coverage run -m pytest test_discount.py && python3 -m coverage report
cd ..

# 4. Демонстрационный тест: связка БД + скидки + стресс-тест
python3 "Наполнение интерфейса, отладка и стресс-тестирование/test_app.py"

# 5. Запуск приложения (Web-UI)
python3 "Наполнение интерфейса, отладка и стресс-тестирование/server.py"
# Открыть в браузере: http://127.0.0.1:8000/
```

## Логика расчета скидки

| Объем, шт.          | Скидка |
|---------------------|--------|
| < 10 000            | 0%     |
| 10 000 – 49 999     | 5%     |
| 50 000 – 299 999    | 10%    |
| 300 000 и более     | 15%    |

При отсутствии истории продаж суммарный объем равен 0 → скидка 0%,
ошибок приложение не выдает (COALESCE(SUM(...), 0)).
