# Учебная практика 05.10.2026

## Требования

- Python 3.10+
- PostgreSQL 16+
- `psycopg2-binary`

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install psycopg2-binary
```

## Подготовка базы

```bash
createdb practice_db_0510
psql -d practice_db_0510 -f "Инфраструктура данных и ETL (База данных в 3NF)/schema.sql"
psql -d practice_db_0510 -f "Реализация ядра бизнес-логики (Расчеты и алгоритмы)/seed_catalogs.sql"
python3 "Инфраструктура данных и ETL (База данных в 3NF)/etl.py"
psql -d practice_db_0510 -f "Инфраструктура данных и ETL (База данных в 3NF)/verification_queries.sql"
```

Схема создаёт таблицы партнёров, товаров, продаж и два справочника для расчёта материалов. `etl.py` загружает «сырые» файлы заказчика: убирает лишние пробелы, приводит даты к формату `ГГГГ-ММ-ДД` и отбрасывает продажу 1003 с несуществующим партнёром 999. В базе остаётся 5 партнёров, 3 товара и 5 продаж.

Подключение настраивать не нужно: приложение само находит локальный сервер PostgreSQL по файлу сокета, в том числе на нестандартном порту. Переменная `PRACTICE_DB_DSN` нужна только для сервера на другой машине или с паролем, например:

```bash
export PRACTICE_DB_DSN="dbname=practice_db_0510 host=db.example.org user=practice password=secret"
```

## Запуск

```bash
python3 "Разработка UI, навигации и CRUD-форм/server.py"
```

Откройте <http://127.0.0.1:8000/>. На главной странице показан список партнёров со скидкой; из него можно открыть карточку партнёра, историю продаж или добавить нового партнёра. По умолчанию сервер слушает `127.0.0.1:8000`; адрес и порт меняются переменными `HOST` и `PORT`.

## Проверки

```bash
python3 -m unittest discover -v -s "Автоматизированное тестирование, аудит безопасности и UX" -p "test_*.py"
```

Тесты проверяют расчёт материалов и скидки, очистку данных, проверку полей формы и параметры SQL-запросов; подключение к базе для них не требуется.

API: `GET /api/partners`, `GET /api/partners/{id}`, `GET /api/partners/{id}/sales`, `POST /api/partners`, `PUT /api/partners/{id}`. Все SQL-запросы с пользовательскими значениями используют параметры.
