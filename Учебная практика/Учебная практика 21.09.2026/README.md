# Учебная практика 21.09.2026

Практика продолжает CRM для партнёров: список с объёмом продаж и скидкой, карточка добавления/редактирования, проверки формы и PostgreSQL API. Всё необходимое для запуска находится в этой директории практики; исходники и данные предыдущих этапов сюда скопированы и адаптированы.

## Требования

- PostgreSQL 16+
- Python 3.10+
- psycopg2-binary

Установить драйвер:

```bash
python3 -m pip install psycopg2-binary
```

## Подготовка отдельной базы

Все команды ниже выполнять из папки «Интеграция формы с БД (CRUD-операции и обновление UI)». Так относительные пути \copy найдут CSV и TXT рядом с SQL-скриптами.

```bash
createdb practice_db_2109
psql -d practice_db_2109 -f schema.sql
psql -d practice_db_2109 -f import_data.sql
psql -d practice_db_2109 -f seed_sales.sql
psql -d practice_db_2109 -f verification_queries.sql
```

Эта база создаётся отдельно. Для импорта используются очищенные файлы с окончанием _clean; исходные файлы оставлены рядом для сравнения. Таблицы содержат партнёров, товары и продажи. Скопированный набор данных нормализован для новой схемы: дробный рейтинг округлён до ближайшего целого, пропущенный рейтинг заменён на 0. Партнёр с ИНН 7702000005 оставлен без продаж, чтобы проверять скидку 0%.

Для другого пользователя PostgreSQL или параметров подключения задайте PRACTICE_DB_DSN, например:

```bash
export PRACTICE_DB_DSN="dbname=practice_db_2109 user=postgres"
```

## Запуск приложения

Из папки интеграции:

```bash
python3 server.py
```

Откройте http://127.0.0.1:8000/. Список открывает карточку партнёра по нажатию; кнопка добавления открывает новую карточку.

## Автоматические проверки

Из папки интеграции запустите:

```bash
python3 -m unittest -v test_discount.py test_app.py
```

test_discount.py проверяет границы расчёта скидки, test_app.py — проверку полей API без подключения к базе. Импорт и полный цикл CRUD требуют запущенного PostgreSQL.

## Проверка в интерфейсе и базе

- Убедитесь, что список показывает партнёров, объём продаж и скидку.
- Откройте партнёра, измените данные и сохраните; проверьте обновлённое значение в списке.
- Добавьте партнёра с уникальными ИНН и email; повторно использованные значения должны дать понятную ошибку.
- Проверьте пустые обязательные поля, дробный и отрицательный рейтинг.
- Измените данные и нажмите «Назад»: приложение предупреждает о потере несохранённых изменений.
- Проверьте партнёра без продаж: объём равен 0, скидка — 0%.
- Запросите несуществующий ID и остановите PostgreSQL: форма должна показать понятную ошибку и не завершиться аварийно.

API: GET /api/partners, GET /api/partners/{id}, POST /api/partners, PUT /api/partners/{id}. Удаление партнёра не предусмотрено.
